# Pocket Invoice: brand and style guide

Generated by tools/ux_pathway.mjs (tools/ux_hifi.mjs) from pocket-invoice-tokens.json and inputs/brand.json. Do not edit: change an input and rerun the script. The same guide as a drawing is style-guide.svg.

Invoices for freelancers, on a phone or a computer.

## Wordmark

A rounded square in color.action.primary with a bold P in color.text.inverse, then the name in bold color.text.default.

## Voice

- Plain words that say what happens next: Create workspace, Send invoice.
- Every error names the fix: Enter a workspace name, not Invalid input.
- Keep what the user typed after every error and every way back.

## Rules

- Colours, type sizes, weights, spacing, radii and borders come only from the token file.
- Text meets 4.5:1 contrast, large text 3:1; control boundaries meet 3:1 (WCAG 2.2, 1.4.3 and 1.4.11).
- Buttons and inputs are at least size.control (48 px) tall, above the 24 px minimum target in WCAG 2.2 (2.5.8).
- Never colour alone: an error also has a bar, the word Error and a message.
- One primary button per screen.

Weights: font.weight.regular 400, font.weight.bold 700. Family: font.family.base, Source Sans Pro, with the system sans-serif as a fallback; the font is not shipped with these files. The token file has no line-height tokens: line height is 1.35 times the size, rounded up to the 4 px grid.
