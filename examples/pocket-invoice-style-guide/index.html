UX-003 and UX-004 · Style guide

Pocket Invoice style guide

The brand, the design tokens and the components of the UX pathway’s example, built as a web page. Every colour, size and space here comes from the same token file as the Penpot file, the SVG drawings, the clickable prototype and the working example. Open your browser’s inspector on any specimen: its styles are --pi-* custom properties, one per token, so you can see which token draws what.

  • Download the token file (JSON, 54 tokens) and the brand file (JSON).
  • The same guide as a drawing: style guide and component sheet (SVG).
  • The components in use: the clickable prototype in high fidelity and the working example.

Brand

PPocket Invoice

Invoices for freelancers, on a phone or a computer.

A rounded square in color.action.primary with a bold P in color.text.inverse, then the name in bold color.text.default.

Voice

  • Plain words that say what happens next: Create workspace, Send invoice.
  • Every error names the fix: Enter a workspace name, not Invalid input.
  • Keep what the user typed after every error and every way back.

Rules

  • Colours, type sizes, weights, spacing, radii and borders come only from the token file.
  • Text meets 4.5:1 contrast, large text 3:1; control boundaries meet 3:1 (WCAG 2.2, 1.4.3 and 1.4.11).
  • Buttons and inputs are at least size.control (48 px) tall, above the 24 px minimum target in WCAG 2.2 (2.5.8).
  • Never colour alone: an error also has a bar, the word Error and a message.
  • One primary button per screen.

Colour

Core colours are the palette. Semantic colours name a job (text, surface, border, action, focus) and point at a core colour; screens use only semantic colours, so a change of palette is one edit.

Sample text on your background

JavaScript is needed to calculate a ratio here. You can inspect the W3C contrast guidance and use another contrast calculator.

Based on WCAG 2.2 contrast for text: 4.5:1 for normal text and 3:1 for large text. Large means at least 24 CSS px, or about 18.67 CSS px if bold. Thresholds use the full calculated ratio; the displayed number is rounded down. This does not check images, transparency, gradients, focus, layout, readability, or overall accessibility.
