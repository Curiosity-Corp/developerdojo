UX-002 and UX-005 · Clickable prototype

Pocket Invoice, a clickable prototype

One screen for each state of the UX pathway’s example flow. Each link moves to the state it leads to, and the number beside it is that transition’s number on the sitemap. Cancel opens a dialog over the form, Escape closes it, and your browser’s Back button goes back one step. Links in a dashed box reach states that no button causes, such as the error after a bad entry.

This is a prototype, so you cannot type anything. The working example is the built version, and the UX pathway has the same screens as SVG files.
