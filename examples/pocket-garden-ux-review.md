## Compare the design and implementation

- Compare the editable SVG journey with the actual screen states. What matches, and what differs?
- Compare the JSON reference values with the example's CSS or computed styles. Record any mismatch and which artifact you inspected.
- Check a text/background pair with an appropriate contrast tool. Record the pair, result, threshold and limits; a contrast pass alone is not full accessibility.
- Note any screen-reader, zoom, motion, touch-target or usability checks not performed.

## Adapt the task

Change the concept to a reading list. Design an empty state and a reversible Read action. Record the new screen states, checks and any reviewer feedback you actually receive. The Pocket Garden example itself has no empty state or saved account.
