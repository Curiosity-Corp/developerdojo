Build in the cloud

Choose a provider. Follow its official training. Come back for a Dojo challenge.

Choose your workshop

These links lead to the providers’ own learning materials. You can explore the reading first and decide whether to use your own cloud account for hands-on work.

Free learning and free cloud usage are different. Offers, limits, account requirements and prices can change. Check them for your account, set appropriate alerts, and remove resources you no longer need. A budget alert alone does not stop spending.

Azure

Connect a workflow to a function

Learn the parts, then follow Microsoft’s guide to call Azure Functions from Logic Apps.

Explore official trainingOpen the official exercise

Before you start: Microsoft Learn reading is free. Hands-on Azure resources require a subscription; Microsoft says its Learn sandboxes are no longer available. Check your plan and pricing before creating resources. Check current terms.

Access: Use only the permissions needed for your exercise. Review who can trigger the workflow and function; keep keys and trigger URLs private. Read the provider guidance.

When finished: Review and remove the workshop resources you no longer need, including related storage and monitoring. Deleting a resource group also deletes its other resources; inspect it first. Read cleanup guidance.

Dojo follow-up

Sketch the trigger, workflow, function and output. Explain what the workflow should do when the function fails.

Quick check: Which part runs custom code, and which coordinates the workflow?

Azure Functions runs the function code; the Logic Apps workflow coordinates steps and can call that function.

AWS

Build an API backed by a function

Use AWS training and its hands-on guide to connect API Gateway to Lambda.

Explore official trainingOpen the official exercise

Before you start: AWS offers free digital learning. The hands-on exercise needs an AWS account and can be possible within Free Tier limits; check eligibility and current charges for your account. Check current terms.

Access: Check whether your API route can be called publicly. AWS recommends an authorizer for each HTTP API route; give the function and your account only the permissions they need. Read the provider guidance.

When finished: Follow the tutorial cleanup for the API, Lambda function, log group and execution role. Confirm each is your workshop resource before deleting it. Read cleanup guidance.

Dojo follow-up

Draw the path from request to response. Describe one input your function should reject and how you would test it.

Quick check: What happens when a request reaches the HTTP API?

API Gateway routes the request to the Lambda function, then returns its response.

Oracle Cloud

Create a Linux cloud server

Start with Oracle’s training, then follow its tutorial for a Linux compute instance.

Explore official trainingOpen the official exercise

Before you start: An Oracle Cloud account is required; registration generally needs a phone number and credit card. A time-limited trial and Always Free resources are different. Always Free compute must be in your home region and may lack capacity; check eligibility and limits. Paid selections or usage outside allowances can incur charges on an upgraded account. Check current terms.

Access: Protect the private SSH key and never paste it into an assistant. Review network rules and restrict SSH access to trusted sources. Read the provider guidance.

When finished: Terminate only the practice instance when finished. Oracle preserves its boot volume by default, so review that volume and other workshop resources separately before removing them. Read cleanup guidance.

Dojo follow-up

List the instance, network and access controls your tutorial created. Explain how you will confirm their cost and remove what you no longer need.

Quick check: What should you check before assuming a server is Always Free?

Check that the selected resources are Always Free eligible for your account and region, and remain within the current limits.

Google Cloud

Deploy an HTTP function

Explore Google Cloud training, then follow the console quickstart for a Cloud Run function.

Explore official trainingOpen the official exercise

Before you start: Training and labs have different access and pricing. The cloud quickstart requires a Google Cloud project and billing setup; check available credits and charges, including related resources. Check current terms.

Access: The linked quickstart asks you to allow public access. That allows unauthenticated calls; choose it only for a non-sensitive exercise you intend to expose, or follow Google’s authenticated alternative. Read the provider guidance.

When finished: Review the service and the Artifact Registry image repository, which can incur storage charges. Deleting a project deletes its other work too; inspect resources before choosing what to remove. Read cleanup guidance.

Dojo follow-up

Describe what the function returns, test an expected input, and list the resources you need to review or clean up.

Quick check: Why check the resources used by a function, not just the function itself?

Related resources can have their own charges and lifecycle; deleting or stopping one service might not remove everything.
