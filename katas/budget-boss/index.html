A real comparison · historical snapshot

The SWE-agent authors compared agent setups using GPT-4 Turbo (gpt-4-1106-preview) on 300 software issue tasks from SWE-bench Lite. The figures below come from their paper’s methods and Table 1, version dated 11 November 2024. This was the authors’ experiment, not a Dojo run.

Shell-only agent

11% of tasks resolved

$1.46 average API inference cost for resolved instances

SWE-agent

18% of tasks resolved

$1.67 average API inference cost for resolved instances

In this benchmark, an issue counts as resolved when the generated patch passes the associated tests. The authors describe their cost metric as API inference cost averaged over successfully resolved instances, with a $4 per-instance budget. It excludes failed instances from that average; it is not the average cost per attempt or the total cost of achieving a success.

These are old research measurements, not current pricing, a universal ranking or a promise of production quality. Tools, prompts, model versions, tasks and prices change. The figures do not capture every possible cost. Inspect the experiment and its limitations.
