What's inside a building model?

A wall, an opening, a window—and the information connecting them. Investigate a real IFC sample with an AI assistant.

Start on your phone

Find the evidence

  1. Open the IFC sample on GitHub. Use your browser’s find-in-page to find IFCWALL(, IFCOPENINGELEMENT( and IFCWINDOW(. The source is plain text, but it describes a model rather than a prose document.
  2. Find IFCRELVOIDSELEMENT and IFCRELFILLSELEMENT. Follow their # references to see how the objects relate. Find IFCRELCONTAINEDINSPATIALSTRUCTURE to identify the storey.
  3. Download the sample yourself or copy the relevant lines into an assistant you trust, with the prompt below. An assistant may not be able to open a link; supply the source rather than assuming it has read the file. Review service terms and avoid private project data.
  4. Check the assistant’s entity numbers against the original. Record the schema, unit, relationship, unknowns and a source link in a short evidence table.

Outcome: an evidence table about a real IFC sample. Harness and model: an assistant and model you can access on a phone, browser or computer. Check your work

Can you prove it?

The reference numbers below are local to this particular file; they are not persistent identifiers across exports. A model can contain many different walls and windows.

Reveal the source checks
  1. FILE_SCHEMA says IFC4. The project’s length unit at #8 is millimetres; the area unit at #9 is square metres. Do not mix them.
  2. #45 is the wall, #80 is the opening and #102 is the window. #85 relates the wall to the opening; #112 relates the opening to the window.
  3. #44 places the wall and window in storey #38. The wall’s property set #49 is attached by #60; #56 records IsExternal as true.
  4. The wall’s FireRating at #52 is an empty label. It does not prove a fire rating. Report it as missing, not as a pass or failure against an unstated requirement.

Our example table records observations from the pinned source; it is not an automated validation report. An IFC file can carry geometry and information, but being IFC does not prove the information is complete, the geometry is correct or a building is safe.

Change the constraint

A client now asks for a verified fire rating. Add an issue to your evidence table: identify the missing value, who should supply it, and what independent evidence or qualified review is required. Do not invent a rating or assert which regulation applies.

Go further on a computer

These optional commands come from IfcOpenShell’s installation guide and validation documentation. They download and run third-party software on your computer. Review the package, its license, compatibility and permissions first. The Dojo has inspected the sample, but has not executed these commands on your device.

Open the pinned IFC sample above, choose GitHub’s download raw file action and save it as model.ifc in a new practice folder. Install a compatible Python version, open a terminal in that folder and use a separate virtual environment:

macOS or Linux
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ifcopenshell
Windows PowerShell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install ifcopenshell

If your organization restricts activation scripts, follow its approved Python setup instead of changing its security policy.

Then run the published syntax and schema checks. Read the actual output and record any exceptions; do not assume the sample passes every validator or project rule.

python -m ifcopenshell.simple_spf model.ifc
python -m ifcopenshell.validate model.ifc --rules

Neither check establishes dimensions, coordination, building-code compliance or construction readiness. An experienced BIM professional must independently review project information and any regulated deliverable; this practice does not grant a qualification.
