The outcome

A table of every property on the wall and window, with its value, its IFC type and whether it is empty.

For: Learners who finished BIM-001.

Done when

  • Every property in Pset_WallCommon and Pset_WindowCommon is listed with its IFC type
  • Empty labels are marked as empty, not as values
  • Your table matches /examples/bim-pathway/generated/original/properties.json

You make: Property table. Outcome: Read property sets.

The Dojo’s worked example, made by the maintainers rather than by a learner: buildingSMART’s wall-with-opening-and-window sample, a practice IDS, an edited copy and every check result, computed by the site’s CI.

Stack recipes

  • Ifcopenshell and python

Why this stack

IfcOpenShell and IfcTester are open source, run offline once installed and implement the buildingSMART IFC and IDS standards, so every learner can rerun the same checks on the same file and get the same output. CI runs the identical script on every pipeline.

Alternatives

  • A desktop BIM authoring tool (for example Bonsai for Blender, or a commercial tool). Shows the model visually and edits it by hand, but results depend on the tool and its export settings. Not tried for this pathway. Not tested for this recipe.
  • A web IFC viewer. Lets you look at the geometry in a browser without installing anything, but a viewer is not a validator. No viewer was checked for this pathway. Not tested for this recipe.

Agents and review gates

  1. Drafting assistant

    Drafts a script that prints each property set as a table.

    Review gate: You check three values by hand in the file before you trust the script.

  2. Learner as reviewer

    Decides which empty properties matter for the brief.

    Depends on: Drafting assistant

    Review gate: Every empty property in the table is either explained or turned into a question for the author.

Setup and smoke test

  1. Create a virtual environment with Python 3.12: python3.12 -m venv .venv
  2. Install the pinned packages: .venv/bin/pip install --require-hashes -r /examples/bim-pathway/tools/requirements.txt, or pip install ifcopenshell==0.9.0.post1 ifctester==0.9.0
  3. Download the sample model and the practice IDS from /katas/bim-pathway into a new, empty folder. Work on copies; keep the original.

Sign-in and access: None. Nothing here needs an account.

Failures and corrections

  • Observed: A script prints FireRating as a value, so it looks filled in Correction: The value is an empty IfcLabel. Print the raw value and its type, and treat an empty string as missing.

Adapt it

  • Add the window type's property sets Properties can sit on the type (IfcWindowType) as well as the occurrence; say which one wins when both exist.

Belt evidence

Belt stages are proposed practice stages, not issued credentials. Evidence below is what a reviewer would look for; it is not a record that anyone has shown it.

Evidence a reviewer looks for

  • A property table for the wall and window that matches the Dojo's CI output, with empty values marked (Automated check, against Industry Foundation Classes (IFC))
  • The learner explains why an empty label is not the same as a recorded value (Self-check)

Belt criteria

  • Practice: Lists Pset_WallCommon and Pset_WindowCommon with types and marks the empty labels
  • Adapt: Finds the empty properties in another openly licensed model
  • Demonstrate: Turns a property table into a short list of questions for the model's author

Professional review
Required. Any real use of this outcome needs independent validation and any approval required from a qualified professional. Practice here does not grant a licence.

Standards in scope

  • Industry Foundation Classes (IFC), IFC4 ADD2 TC1 (ISO 16739-1:2018), as declared by the sample file. Applies to: The buildingSMART practice sample and copies of it only. Review scope: What the listed checks test: the schema the file declares, its entities and relationships. No claim about any real building.

Maintenance and caveats

Review cadence: Every six months, when IfcOpenShell or IfcTester releases a new minor version, or when buildingSMART revises IFC or IDS

  • This recipe is a draft: the example was built and checked by the Dojo maintainers and CI, and no learner has run it yet.
  • The sample is a three-element test file, not a building. Nothing learned from it is evidence about a real project.
  • No model, property value or check result here is professionally reviewed or approved. A real project needs the qualified people its contract and jurisdiction name.
  • Information (IDS), schema and geometry checks are separate outcomes. Passing one says nothing about the others, and there is no combined score.
  • Property values in a sample model are test data. A thermal transmittance or rating in this file is not a product or design value.
