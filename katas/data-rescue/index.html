02 / Your turn

Copy the prompt. Make it yours.

Open a new chat in ChatGPT or Claude, paste this prompt, and replace anything you want to change.

You can also select and copy the text.
Make this prompt about your idea

Your details stay in this browser page; the Dojo does not save or send them. If you paste the prompt into an assistant, that service receives it. Avoid private information you do not have permission to share.

JavaScript is needed to assemble a personalized prompt here. You can still select and copy the original prompt above, then edit it in your assistant.

03 / Your ingredients

A simple stack

Harness
ChatGPT or Claude app, or either service in a browser.
Model
A model available in your chosen chat. Access and limits depend on your account.
Instructions
The complete prompt above. Change the topic and constraints to fit your goal.
Context
Your idea and any non-sensitive details you choose to share.
Skills, CLI, MCP, plugins or connectors
None needed for the basic chat version. Optional ways to equip your setup are below.
Agent and verification
One chat assistant drafts; you inspect the result against the checks below and ask it to fix problems.

04 / Pick your setup

Use the device you have

Choose one path. You can do the chat exercise without installing a command line tool.

Phone · ChatGPT app

Open the ChatGPT app, start a new chat, and paste the prompt. Ask the assistant for the requested result. Some account-available plugins can be used on mobile; desktop-only plugins cannot. Plugins are optional here. ChatGPT plugin guide.

Phone · Claude app

Open the Claude app, start a new chat, and paste the prompt. Ask for the requested result. Remote connectors are optional; local desktop extensions do not run on the phone. Claude connectors guide.

Windows

Open ChatGPT or Claude in a browser and paste the prompt. Alternatively, install one CLI in PowerShell using an official command below. These commands download and execute installers; check the linked vendor instructions first. Sign in when prompted; eligibility and plans vary. Use a folder you are comfortable granting the tool access to.

Codex CLI (official setup):

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
codex

Claude Code (official setup; an eligible paid or other supported account is required):

irm https://claude.ai/install.ps1 | iex
claude

Then paste the same prompt into the CLI. Review any access or changes it asks to make.

05 / Check and remix

Make sure it works for you

  1. Check that the repeated S102 row is counted once, and that S104 and S105 are listed as exceptions.
  2. Check the complete rows: 2 × $3, 1 × $4, 3 × $3 and 1 × $3. The total is $22 across seven items.
  3. Check that “Basil” and “basil” are grouped together and that missing values were not invented.
  4. If a check fails, tell your assistant exactly which row is wrong and ask for a corrected report.

Check your three numbers

This checks the numbers for the fictional seed dataset. You still need to inspect the rows and the explanation.

Remix: use a small dataset you are allowed to share, and define how to handle duplicates and missing values before calculating.
