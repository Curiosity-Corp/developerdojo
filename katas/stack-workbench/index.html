Record the version shown and sign in when prompted. Paste prompt A into the session. For B, exit with /exit, run claude again and use the same model and settings where available. Review any requested permissions; this exercise asks for HTML in the response, not file edits or commands. Existing instructions, skills, plugins or MCP servers can still affect a session: inspect your configuration and record anything unknown. Do not bypass permission prompts.

Another trusted CLI harness can be used instead; consult its official setup, version and permission guidance. Do not mix harnesses during the A/B comparison.

  1. Filters: All shows Basil, Sunflower and Mint; sun shows Basil and Sunflower; shade shows Mint.
