Manufacturing · Pathway

From a process record to control limits and the sources of variation.

Four katas on statistical process control, on a real semiconductor record and the published results of the NIST/SEMATECH e-Handbook. Each step has a file you can open and a result that CI computes again on every pipeline.

Start with MFG-001Download the wafer subgroups

01 / The files

One process record, the handbook’s results, every number rerun

The record is the lithography case study of the NIST/SEMATECH e-Handbook of Statistical Methods: the width of a line on silicon wafers, measured at five sites on three wafers in each of thirty cassettes. The handbook publishes its summary, its analysis of variance and the methods for control charts and capability, with worked examples. The script reproduces those values before it computes anything else.

  • The process record: the 450 data rows of the handbook’s file, unchanged. The file’s header is left out because it names a person; the README describes its columns.
  • The 90 wafer subgroups (CSV) and the control limits (JSON).
  • The record inspection and the variance components (JSON).
  • The result summary (Markdown) and every result under the manifest, with the method and the input hash.
  • The pathway script (Python 3.12, standard library only, MIT), so you can rerun every number yourself.
  • README: sources, terms, how to rerun the checks, and what they do not cover.

02 / The steps

Four katas, in order

Each kata has a brief, prompts, checks and the evidence for the checks the Dojo has run. They are drafts: the Dojo built the example and CI checks it, and no learner has run them yet. Do the foundations first: Compare AI instructions and Spot a context trap.

  1. MFG-001 Inspect a process record

    Work out how 450 line widths are grouped, check nothing is missing, and reproduce the handbook’s numerical summary.

  2. MFG-002 Set control limits and choose the subgroup

    Rebuild the chart factor table from the range distribution, then set limits with the wafer as subgroup and chart the cassette means on their own.

  3. MFG-003 Split the variation into its sources

    Reproduce the nested analysis of variance and the handbook’s capability example, and see which sigma a capability index must use.

  4. MFG-R01 Manufacturing Randori: an unseen change

    A partner reveals one changed choice after you start; predict how the limits and the points outside them move, then recompute.

The chart factors are not copied from the table: the script works out d2 and d3 from the distribution of the range of normal samples. Result (JSON).

  • D4, n = 5: The range distribution gives D4 = 2.114499 (d2 = 2.32593, d3 = 0.86408), which rounds to 2.114; the handbook prints 2.115. Accepted within one unit of the last printed digit.
  • Rejects at Cp 1.33 (limits 8 sigma apart), ppm: Limits 4 sigma either side leave 2 x Phi(-4) = 63.3 ppm outside, which rounds to 63; the handbook prints 64. Accepted within one unit of the last printed digit.

The record (MFG-001)

450 line widths in micrometres: 30 cassettes, 3 wafers in each, 5 sites on each wafer, and nothing missing. Mean 2.53228, standard deviation 0.69376, lag-1 autocorrelation 0.60726: successive values are far from independent, because the record is grouped. The center site has the lowest mean. A capability index divides by its sigma, so one computed with the chart’s sigma would be 1.61 times too large for single sites. The case study publishes no specification limits for line width, so no capability index is computed for it. The handbook’s own example (USL 20, LSL 8, mean 16, s 2) gives Cp 1.0000 and Cpk 0.6667. 04 / The tools and sources

No packages, public sources

The script uses only the Python 3.12 standard library, so it runs offline with nothing to install. A spreadsheet works for checking one subgroup by hand. The Armory lists the stack recipe Python standard library.

  • NIST/SEMATECH e-Handbook of Statistical Methods, web edition last updated 27 April 2022 (DOI 10.18434/M32189).
  • Section 6.1.6, process capability: the indices, the capability example and the table of rejects.
  • Sections 6.3.2, 6.3.2.1 and 6.3.2.2: variables control charts, c4, the factor table and the individuals chart example.
  • Section 6.6.1, the lithography case study, and its data file.
  • ISO 7870-2:2023, Control charts, Part 2: Shewhart control charts, the current international standard for these charts. Cited only: the Dojo has not read its text, and nothing here claims conformance to it.

05 / What is checked

Verified, and not verified

Verified

  • The process record is the 450 data rows of the handbook’s file, unchanged (SHA-256 d7c27b047ed0…, checked by the site’s tests).
  • The script reproduces 60 values the handbook publishes (the case study’s summary, analysis of variance and variance components, the X-bar and R factor table rebuilt from the range distribution, c4, the individuals chart example, and the capability example and rejects table) and refuses to write any result if one differs. Two printed values are one unit off in their last digit, and the checks say why. (evidence)
  • With the wafer as subgroup, 27 of 90 wafer means fall outside the X-bar and s limits: the cassette-to-cassette variation, 54.0 % of the total, is not in those limits. (evidence)
  • On every pipeline, CI reruns the script with Python 3.12 and fails if any output differs from the files on this page. (evidence)

Not verified

  • Any real process, part or quality system. The record is the handbook’s case study; nothing here says that a real process is in control or capable, or that a chart meets ISO 7870-2 or any other standard.
  • A capability index for the case study: it publishes no specification limits, so none is computed for its line widths.
  • Attribute charts, CUSUM and EWMA charts, run rules beyond the three-sigma limits, measurement system analysis and non-normal capability.
  • The text of ISO 7870-2:2023, which is cited but was not read.
  • Use by real learners: no learner has run these katas yet.

Professional review: None. No quality engineer, statistician or process engineer has reviewed this pathway; a real process needs the review its quality system requires.

What this field adds to the shared foundations

Terms of the field

Subgroup
The measurements charted together as one point, such as the five sites of a wafer; the limits carry only the variation within subgroups (handbook 6.3.2.1).
Control limits
Lines three standard deviations of the charted statistic either side of its centre, computed from the process’s own data, which tell whether a process is in statistical control (handbook 6.3.2).
Specification limits
The limits a part must meet to work as intended, set by its design, not by the process; not the same as control limits (handbook 6.3.2).
Moving range
The absolute difference between two successive individual values; its average divided by 1.128 estimates sigma for an individuals chart (handbook 6.3.2.2).
Variance component
The share of the total variance that comes from one source, such as cassette, wafer or site, estimated from a nested analysis of variance (handbook 6.6.1.3).
Process capability (Cp, Cpk)
How the spread and centring of a process in control compare with its specification limits: Cp = (USL - LSL) / 6 sigma, and Cpk the smaller of the distances to each limit over 3 sigma (handbook 6.1.6).

Procedures practised

  1. Inspect a process record: its grouping, completeness and numerical summary (MFG-001)
  2. Set Shewhart control limits from the process’s own data, with a subgroup you can defend (MFG-002)
  3. Split the variation into its sources and choose the sigma a capability index uses (MFG-003)
