# Resource catalog accessibility-scan profiling

Issue #113 tracks the slow full-page accessibility scan. `catalog_a11y_profile` is an optional diagnostic; the existing `e2e` job still runs and blocks release. After the normal jobs finish, use **Build > Pipelines** on an MR or `master` pipeline and start the manual job. Wait for it to finish, then download `catalog-a11y-profile.json`. Running it while other browser jobs run adds contention and makes the observations less useful.

The job uses the built site and a single Chromium process on one CI runner. It opens a fresh browser context for each full scan, applies the same WCAG tags used in the release check, and keeps all catalog cards. It runs four scans per theme: baseline then temporary `content-visibility: visible` override, followed by the reverse order. The dark theme starts with the reverse sequence. Each sample records order, theme, setup and scan times, Chromium and user-agent information, resource and DOM counts, effective CSS, all axe violations and incomplete findings. The override exists only in the experiment's page; it does not change the site.

Compare both samples for each theme and treatment, including every violation and affected node. Investigate any difference before considering a CSS change. Two pairs are exploratory and cannot establish a reliable speedup or cause; repeat on separate runs and consider changing runner load. A failure or partial artifact may indicate an interrupted scan or setup failure. The job fails if a scan finds a serious or critical violation in either treatment, while the normal blocking checks retain their own independent result.

These measurements describe a shared CI runner. They do not measure real-device navigation, filtering, layout or paint, and they do not replace a person's accessibility review. If the override makes axe faster, assess learner-facing rendering and accessibility separately before proposing an actual change. Do not remove catalog entries, filters, no-JavaScript access, WCAG rules or browser checks to improve a measurement.
