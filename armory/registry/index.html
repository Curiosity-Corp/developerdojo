A starter registry, not an installation

These are source-backed starting points, not a ranking. The documentation and linked license information were checked on 7 November 2026. No tool was installed, connected, runtime-tested or independently security-audited for this registry. Versions, access, plans and compatibility can change.

Claude Code

Anthropic · official

A coding agent for working with files and commands in a terminal and other supported surfaces.

Compatibility, access and verification
Compatibility
See the official platform and setup guide for supported systems, account and provider options.
Access and cost
It may read and edit files and run commands according to its configuration and permissions. Review the work folder and approvals.
License and terms
Product and service terms apply; account access and charges depend on your plan.
Try a verification

Choose a stack for your task

  1. Name the outcome and choose an assistant or harness you can access.
  2. List the data, files and actions the task actually needs. A skill is instructions; an MCP server or CLI may provide actions.
  3. Inspect the source, version, license, permissions and compatibility. Start with fictional data and the smallest useful access.
  4. Check the output and record what you tested. A successful installation or a model’s assurance does not prove the result is correct.
