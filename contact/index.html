What to write in the subject line

Start your message with one of these subjects so it reaches the right person.

  • Be told when live sessions open. Subject: Developer Dojo: tell me about sessions
  • Submit a Build Sprint. Subject: Build Sprint: <challenge name>
  • Become a sponsor. Subject: Sponsor Developer Dojo
  • Offer to mentor or review. Subject: Developer Dojo: mentor
  • Report a conduct problem. Subject: Conduct
  • Ask anything else. Subject: Developer Dojo: question
